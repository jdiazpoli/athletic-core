## Tecnologías

- **Frontend:** Angular (carpeta `frontend/`)
- **Backend:** API REST en Java con Spring Boot (carpeta `backend/`)
- **Base de datos:** SQL – MySQL (scripts en `database/`)
- **Pagos:** Mercado Pago / PayU en modo de pruebas (sandbox)

## Estructura

```
frontend/   Aplicación Angular (módulos Usuarios, Catálogo, Compras, Administración)
backend/    API REST Spring Boot (usuarios, catálogo, carrito y pedidos, pagos, inventario)
database/   Scripts SQL: creación de tablas y carga de los 20 artículos
docs/       SRS, SDS, manual de usuario, actas y TSPi Workbook
```
